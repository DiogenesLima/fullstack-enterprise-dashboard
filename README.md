# Enterprise Modern Monorepo 🇬🇧

Professional showcase of a distributed system architecture targeted at the UK tech market.

## 🏗 Stack & Engineering
- **Monorepo Management:** Turborepo + pnpm Workspaces
- **Frontend:** Nuxt 4 (SSR, Layers, Nitro)
- **Backend:** NestJS (Modular Architecture, Swagger, TypeORM)
- **Shared:** Unified API Contracts & TypeScript Configurations
- **Infrastructure:** Docker Compose, GitHub Actions (CI/CD)

## 🎯 Project Goals
The goal of this repository is to demonstrate engineering experience, built along 25 years, translated into modern web standards, focusing on:
- Strict Type Safety (End-to-end)
- Scalable Folder Structure
- Professional DevOps Workflow
